## 📄 Sobre el Proyecto

Este proyecto consiste en una **Línea del Tiempo Interactiva Web** que analiza de manera técnico-científica la evolución del automóvil a lo largo de 257 años de historia (desde el *Fardier de Cugnot* en 1769 hasta las tecnologías de descarbonización y baterías de estado sólido hacia el 2026+).

El proyecto fue publicado y se encuentra completamente desplegado y funcional en GitHub Pages:
🔗 **[Ver Sitio Web Interactivo](https://xdxd1945.github.io/linea-de-tiempo-automobil-Ricardo-Reyes/)**

## 🛠️ ¿Cómo se realizó este trabajo?

### 1. ¿Por qué en HTML/CSS/JS y no en Canva?
Sinceramente, no sé usar Canva ni herramientas tradicionales de diseño gráfico orientadas a plantillas rígidas, pero la **programación** se me da bastante bien. Aprovechando que el fin de semana estaba aburrido y que ya había terminado con anticipación el trabajo de Geometría, decidí construir la línea del tiempo desde cero como una aplicación web nativa usando **HTML5, CSS3, JavaScript** y componentes interactivos (fichas desplegables, filtros dinámicos por categorías y canvas de fondo).

### 2. Flujo de Trabajo y Curaduría de Datos con IA
Para garantizar que toda la información técnica y científica del proyecto fuera **100% verídica, exacta y libre de errores de alucinación**, diseñé un flujo de automatización y validación utilizando múltiples Modelos de Lenguaje (IAs):

1. **Automatización de Extracción de Datos:** Se automatizaron consultas a un grupo de IAs especializadas en ingeniería y termodinámica para extraer datos específicos de cada hito (cilindrada, arquitectura de motores, tipo de combustible, aleaciones de materiales, tiempos de ensamble y patentes).
2. **Fase de Redacción y Estructuración:** La información recopilada se organizó dentro del código fuente respetando una estructura clara de *Motorización*, *Chasis/Transmisión*, *Razón de la Evolución* e *Impacto Histórico*.
3. **Verificación Rigurosa Multimodelo (Auditoría Final):** Al finalizar la codificación del proyecto, utilicé un grupo independiente de IAs a modo de "comité de revisión técnica". Este grupo analizó de forma exhaustiva el sitio web publicado para auditar y verificar:
   - Fechas exactas y nomenclaturas de patentes (ej. *DRP 37435* de Benz).
   - Datos cinemáticos y térmicos.
   - Especificaciones técnicas de cada uno de los 15 hitos históricos.

## 📊 Estructura y Contenido del Sitio

El sitio cuenta con:
* **15 Hitos Históricos Clave:** Desde la propulsión a vapor hasta arquitecturas de 800V y software-defined vehicles (SDV).
* **Fichas Técnicas Desplegables:** Fichas que se expanden al hacer clic para ver detalles profundos de cada ingeniería.
* **Sistema de Filtros:** Filtrado dinámico por categorías (Propulsión, Seguridad, Masa/Ensamblaje, Electrónica/Digital, etc.).
* **Diseño Responsivo e Interactivo:** Adaptado para su perfecta visualización en computadores, tablets y teléfonos.

## 💻 Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de las tarjetas e hitos históricos.
* **CSS3:** Estilos visuales, animaciones, layout mediante Grid/Flexbox y variables CSS.
* **JavaScript (Vanilla JS):** Lógica interactiva para abrir/cerrar fichas, aplicar filtros de categoría y manejar eventos.
* **HTML5 Canvas API:** Fondo interactivo dinámico.
* **Git & GitHub Pages:** Control de versiones y alojamiento web.
