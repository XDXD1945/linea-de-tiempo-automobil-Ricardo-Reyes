## 📄 Sobre el Trabajo

Hice este proyecto como una **línea del tiempo interactiva en formato página web**. Recorre la historia del auto desde el primer vehículo a vapor en 1769 hasta lo que se viene para el 2026 con los autos eléctricos y nuevas tecnologías.

## 🛠️ ¿Cómo hice el proyecto?

### 1. ¿Por qué lo programé en HTML/CSS/JS y no usé Canva?
La verdad es que **no sé usar Canva** (las plantillas no se me dan muy bien), pero la **programación sí se me da bastante bien**. Como el fin de semana estaba medio aburrido y ya había terminado el trabajo de Geometría, me puse a armar la página desde cero con HTML, CSS y JavaScript para que fuera interactiva y quedara bien armada.

### 2. Uso de IAs para buscar y revisar la información
Para armar todo el contenido y no perder horas buscando dato por dato, usé un flujo con varias IAs:

1. **Búsqueda de datos:** Programé consultas automatizadas con un grupo de IAs para que me recopilaran la información de cada auto (motores, velocidades, fechas, materiales y cambios clave).
2. **Armado de la página:** Con esos datos estructuré el código y dejé listas las fichas desplegables y las imágenes.
3. **Revisión final:** Al terminar, le pasé el proyecto a otro grupo de IAs para que revisaran si los datos tenían sentido. *(Nota: Aunque la información quedó súper completa y bien revisada por las IAs, como es un trabajo tan largo igual se puede haber pasado algún error o detalle en las fechas/datos).*

## 📊 ¿Qué tiene la página?

* **15 momentos importantes:** Muestra los saltos más grandes que ha dado el auto en la historia.
* **Fichas desplegables:** Le puedes dar clic a cualquier auto para abrir más detalles de cómo funcionaba.
* **Filtros por categoría:** Se puede filtrar por tipo de motor, seguridad, tecnología o historia.
* **Diseño para celular y PC:** Se adapta a cualquier pantalla.
